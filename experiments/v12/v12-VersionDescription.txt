v12-押韵：版本说明（2026年6月5日）



1. 基于v9作出更改，目前只训练了五言诗和七言诗，没有词；此模型不保证百分百押韵；有两种模式，指定韵脚或者不指定，详见命令行示例。



2. 改动原理如下：
利用“已知体裁（五言/七言）”来精确计算每个字在句中的位置，从而在偶数句的最后一个汉字生成时施加约束。主要改动包括：
1）在 generate_one 中根据 genre 确定每行字数（5或7），并新增 chars_in_line 变量实时跟踪当前行已生成汉字数；
2）当 chars_in_line == line_length - 1 且 line_count 为奇数（偶数句）时判定为押韵位置；
3）第一个押韵位置正常采样后提取韵母作为全诗韵脚（并检查韵母是否“友好”，否则重试）；
4）后续押韵位置如果采样结果不押韵，则调用 sample_rhyme_only 从该韵母对应的汉字集合中强制重新采样；
5）最后在每次生成后更新 chars_in_line，遇到标点时重置行计数。通过这种方式，模型能精确锁定句末汉字进行押韵干预



3. 修改predict文件，新增rhyme_util.py和build_rhyme_dict.py：
prepare_data.py	新增	生成汉字→韵母映射表 rhyme_dict.json
rhyme_utils.py	新建	韵母工具模块（加载映射、获取韵母、判断押韵）
predict.py	修改	增加押韵参数和生成逻辑



4. 注意需要pip Install pypinyin
完整命令：
pip install torch datasets opencc-python-reimplemented pypinyin matplotlib
python prepare_data.py
python build_rhyme_dict.py #切记！！这是在构建汉字到韵母的映射表
python train.py --genre 5 --use_topic --epochs 10 --batch_size 32 #训练五言诗（有主题）
python train.py --genre 7 --use_topic --epochs 10 --batch_size 32 #训练七言诗（有主题）
（注意何馨怡六月五号训练使用的是epoch = 10，但这未必最佳（此时val_loss大致为4.6），实际上epoch = 3极有可能可行）
# 五言山水诗，自动押韵，重复惩罚系数1.3
python predict.py --genre 5 --prompt 春 --topic landscape --auto_rhyme --rep_penalty 1.3 --lines 4
# 七言边塞诗，指定韵脚，重复惩罚1.2
python predict.py --genre 7 --prompt 雪 --topic frontier --rhyme ue --rep_penalty 1.2 --lines 8



5.完整流程示例：
# 1. 安装依赖
pip install torch datasets opencc-python-reimplemented pypinyin matplotlib

# 2. 数据准备（约2-5分钟）
python prepare_data.py

# 3. 构建韵母表（约30秒）
python build_rhyme_dict.py

# 4. 训练五言模型（约3-5分钟）
python train.py --genre 5 --use_topic --epochs 3 --batch_size 32 --train_num_samples 50000

# 5. 训练七言模型（约3-5分钟）
python train.py --genre 7 --use_topic --epochs 3 --batch_size 32 --train_num_samples 50000

# 6. 测试生成
python predict.py --genre 5 --prompt 春 --topic landscape --auto_rhyme --lines 4 #不指定韵脚
python predict.py --genre 7 --prompt 月 --topic frontier --rhyme ang --lines 8 #用户可以指定韵脚
