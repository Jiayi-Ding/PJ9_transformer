V13 四个结构参数调参结果分析

实验说明

d_model=256, n_layer=4, d_ff=1024, n_head=8, epochs=6, train_num_samples=150000。

每次只改变一个结构参数，分别测试：
d_model: 192 / 320
n_layer: 3 / 5
d_ff: 768 / 1280
n_head: 4 / 16

同时分别训练 genre=5 和 genre=7。

二、规律总结

1. 所有实验的 best epoch 都是第 6 轮

这说明在 epochs=6 的设置下，验证集 loss 还没有出现明显反弹。
严格来说，目前没有看到已经发生严重过拟合的证据。
但是部分大模型的 train-val gap 已经明显变大，说明如果继续增加 epoch，过拟合风险会上升。


2. 五言更偏向小模型或轻微正则化

五言最优是 n_layer=3，比 baseline 更好。
d_model=320 虽然 final train_loss 降到 3.5968，但 best val_loss 变差到 4.0002，并且 gap 达到 0.4034。

这说明对五言来说，扩大模型宽度确实提高了训练集拟合能力，但没有提升验证集表现，反而带来了更强的过拟合倾向。


3. 七言明显需要更大容量

七言最优是 d_ff=1280，其次是 n_layer=5。
这两个设置都明显优于 baseline。

说明七言任务相对更难，baseline 模型仍然有欠拟合成分。
增加前馈网络宽度或增加层数，都能提高模型对七言长上下文和复杂结构的建模能力。


4. d_ff 是本轮最值得继续调的参数

d_ff=1280 对五言和七言都有正向效果：
五言 best val_loss 从 3.9800 降到 3.9696；
七言 best val_loss 从 4.1061 降到 4.0389。

相比 d_model 和 n_head，d_ff 的收益更稳定。


5. n_head 不是优先调参方向

五言中 n_head=4 和 n_head=16 都比 baseline 差。
七言中 n_head=16 只小幅优于 baseline，n_head=4 则变差。

当前 baseline 的 d_model=256, n_head=8，每个 head 的维度是 32，比较均衡。
n_head=16 时每个 head 只有 16 维，单个 head 表达能力偏弱。
n_head=4 时 head 数偏少，注意力模式的多样性不足。


三、原因分析

1. 五言为什么 n_layer=3 更好

五言序列更短，结构相对简单。
baseline 的 d_model=256, n_layer=4, d_ff=1024 已经具备足够表达能力。

当层数减少到 3 时，模型容量下降，训练集 loss 略高，但验证集 loss 更低。
这说明五言任务中，适当减少模型深度能降低对训练集细节的拟合，从而提升泛化。


2. 五言为什么 d_model=320 变差

d_model=320 明显降低了训练集 loss，但验证集 loss 没有下降。
这说明扩大宽度后，模型主要学到了训练集中的局部模式或噪声，而不是可泛化的规律。

同时 d_model 增大后，embedding、attention 和输出相关层的参数量都会增加，过拟合风险上升。
从 gap=0.4034 可以看出，它是五言实验中过拟合倾向最明显的一组。


3. 七言为什么 d_ff=1280 最好

Transformer block 中的 d_ff 控制前馈网络容量。
attention 更偏向建模 token 之间的关系，而 FFN 更偏向对每个位置的特征进行非线性变换和组合。

七言句子更长、上下文依赖更复杂，对特征变换能力的需求更高。
因此增加 d_ff 能稳定降低七言的 train loss 和 val loss。


4. 七言为什么 n_layer=5 也有效

增加 n_layer 可以增加模型的层级表达能力。
七言比五言需要处理更长的上下文和更复杂的语义、格律结构，因此更深的模型能带来收益。

不过 n_layer=5 的 gap 也上升到 0.1202，说明继续加深时需要注意过拟合。


5. 为什么 d_model=320 不如 d_ff=1280 稳定

d_model=320 扩大的是整体隐藏维度，会影响 embedding、attention、残差流和输出表示。
但本轮 d_ff 仍固定为 1024，使得 d_ff / d_model 从 baseline 的 4.0 降到 3.2。

也就是说，模型宽度变大了，但前馈网络相对没有同步扩大。
这可能导致额外容量没有被最有效地使用，同时参数量和过拟合风险却增加了。


四、下一轮建议

1. 五言建议优先实验

d_model=256, n_layer=3, d_ff=1024, n_head=8
d_model=256, n_layer=3, d_ff=1280, n_head=8
d_model=256, n_layer=4, d_ff=1280, n_head=8, dropout=0.15

五言当前最稳方向是减少层数，或在控制过拟合的前提下小幅增加 d_ff。


2. 七言建议优先实验

d_model=256, n_layer=4, d_ff=1536, n_head=8
d_model=256, n_layer=5, d_ff=1280, n_head=8
d_model=320, n_layer=5, d_ff=1280, n_head=8
d_model=320, n_layer=5, d_ff=1536, n_head=8

七言当前最稳方向是继续增加 d_ff，并尝试 d_ff 与 n_layer 组合。


五、当前推荐结论

如果五言和七言分别选模型：
五言推荐使用 d_model=256, n_layer=3, d_ff=1024, n_head=8。
七言推荐使用 d_model=256, n_layer=4, d_ff=1280, n_head=8。

如果想用一套相对均衡的参数同时兼顾五言和七言：
d_model=256, n_layer=4, d_ff=1280, n_head=8。
